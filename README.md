# Snake

A classic Snake game built with HTML, CSS, and vanilla JavaScript. No dependencies or build tools are required.

## Play

Open `snake.html` in a modern web browser, or play the game online from the [Snake branch](https://github.com/Spxctrxs/html_games/tree/Snake).

## Controls

- **Arrow keys**: steer the snake.
- **Swipe** on the game board: steer on touchscreens.
- **On-screen direction buttons**: steer on mobile devices.
- **Space**: restart after game over. Tapping a direction also restarts.

Eat the red food to grow and earn 10 points. The snake speeds up every 100 points. Avoid the walls and the snake's body!
